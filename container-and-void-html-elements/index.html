HTML Closing and Void Tag Reference Guide

In HTML, whether a tag requires a closing tag depends on a single rule: Does the element wrap around content, or is it the content itself?

Container elements act like boxes that hold text, media, or other HTML tags. They require an opening tag (<tag>) and a closing tag (</tag>) so the browser knows where the box begins and ends. Void elements are standalone items inserted at a specific point in the document. Because nothing ever goes inside them, they do not have closing tags.

Container Elements (Require Closing Tags)

These elements wrap around content. Even if a container is left intentionally empty, you must still include its closing tag.

Category Common Tags Purpose
Document Structure <html>, <head>, <body>, <title> Defines the core framework and metadata of the webpage.
Layout & Grouping <div>, <span>, <header>, <main>, <footer>, <section>, <nav> Groups elements together for page structure and CSS styling.
Text & Headings <h1>–<h6>, <p>, <strong>, <em> Formats headings, paragraphs, and emphasized text.
Lists <ul>, <ol>, <li> Wraps unordered (bulleted) or ordered (numbered) lists and individual list items.
Links & Interactive <a>, <button> Wraps clickable text or icons for hyperlinks and UI buttons.
Forms & Controls <form>, <label>, <textarea>, <select>, <option> Creates user input forms, labels, multi-line text boxes, and dropdown menus.
Tables <table>, <thead>, <tbody>, <tr>, <th>, <td> Builds structured data grids with rows, headers, and data cells.

Void Elements (No Closing Tags)

These standalone elements cannot hold any text or nested tags inside them. They are configured strictly through attributes inside the single tag.

Category Tag Purpose
Media & Embeds <img> Embeds an image using src and alt attributes.
Media & Embeds <source> Specifies media file sources inside <video> or <audio> containers.
Form Inputs <input> Creates text fields, checkboxes, radio buttons, and submit inputs.
Breaks & Dividers <br> Inserts a single line break within text.
Breaks & Dividers <hr> Creates a thematic break (renders as a horizontal rule/line).
Metadata & Links <meta> Defines document metadata like character encoding and viewport scaling.
Metadata & Links <link> Connects external resources, such as CSS stylesheets, to the document.
